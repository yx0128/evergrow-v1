This is the short entry point. The full reproduction story is in

[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) and [`docs/DESIGN.md`](docs/DESIGN.md).

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
npm run models   # Blender 4.2+; see docs/ART_PIPELINE.md
```

## Non-negotiables

- Desktop-first at `1440×900`. Keep the HUD usable; do not let the diorama hide behind the task drawer.
- Palette: cream, sand, sage, moss, terracotta, rose, gold, slate. No neon, pure white, or pure black.
- Every item is `1×1`. Base tiles are `0.2333` tall in world space; props sit flush at `y = 0.2333`.
- `placedItems` is the single source of truth for the world. Inventory is unplaced stock. Coins never refund.
- Clicking a placed piece selects it in place; `R`/HUD Rotate rotates it, and Move/`M` lifts it. Moving never changes inventory, and a base carries its surface prop.
- Task completion pays once and cannot be undone by toggling a completed checkbox.
- Persisted data is untrusted. Keep `sanitizePersisted` strict and add a test for every new invariant.
- Never commit `node_modules/`, `dist/`, `.env`, tokens, or Blender backups (`*.blend1`).
- Do not rename the localStorage key or storage version without a migration.
- Keep GLB art generated by `scripts/generate_models.py`; do not hand-edit files in `public/models/`.
- Keep the point-light count fixed at ten through `LightingPool`. Never render point lights per miniature.
- Render placed items through `InstancedItemBatch`; the ghost/fallback may use `MiniatureModel`.
- Keep post-processing lazy and gated by `graphicsQuality`; Low must not import the effects chunk.

## Change recipes

**Add an item**

1. Add a definition to `ITEMS` in `src/data/items.ts` (`name`, `shortName`, `category`, `cost`, `modelUrl`, `accent`, `glyph`, optional `light`).
2. Add the id to `HOTBAR_ORDER` so it gets a fixed, reachable slot; keep pages at nine slots.
3. Add a builder to `BUILDERS` in `scripts/generate_models.py` and regenerate (`npm run models`).
4. Add a test to `src/test/worldStore.test.ts` if the item changes layer or light behavior.
5. Run `npm run typecheck && npm run lint && npm test && npm run build` and take a fresh screenshot.

**Change the world economy**

Rewards live in `TASK_REWARDS`; costs live on each item. Starter coins in `STARTER_COINS`. Update the README table and the store tests.

**Change the camera**

Update `DAY_CAMERA` and `CAMERA_TARGET` in `Scene.tsx`; verify at `1440×900` with the task drawer open and closed. Keep `maxPolarAngle` below the horizon.

**Change persistence**

Bump the key version, extend `sanitizePersisted`, and keep backward compatibility for one release. Never hydrate transient UI fields.

## Common failure modes

| Symptom | Fix |
| --- | --- |
| Props float above base tiles | Base tile height normalization must stay locked to `0.2333`; keep `verticalScale` in `MiniatureModel`. |
| Ghost never updates over a tile | The invisible raycast plane must stay at `y = 0` and placed pieces must call `stopPropagation`. |
| Shader stutters when placing lanterns | A point light was added outside `LightingPool`; keep the pool at exactly ten. |
| Instanced pieces cannot be clicked | Map `event.instanceId` back to the visible piece array in `InstancedItemBatch`. |
| Low quality still loads effects | Check the lazy import and `graphicsQuality` gate; the `postprocessing` chunk must not be in the initial request list. |
| Moving a base leaves its prop behind | `beginMove`/`moveTo` must treat a base + attached prop as one group. |
| Clicking a piece makes it follow the mouse | Selection must stay in place; only Move/`M` calls `beginMove`. |
| Left click orbits the camera | `OrbitControls` must use `LEFT: -1`. |
| Duplicate action on a piece | Missing `event.stopPropagation()` in the group click/context handlers. |
| Model is tiny or buried | Re-check `Box3` measurement, `FOOTPRINT`, and `-box.min.y` grounding. |
| Bloom blows out the screen | Keep `luminanceThreshold` at `1.0`; lower `intensity` rather than threshold. |
| Night is unreadable | Keep ambient/hemisphere fill; lantern point lights are supplemental. |
| Store tests fail on Node 26 | jsdom may expose no `localStorage`; `src/test/setup.ts` polyfills it. |
| Preview shows another project | Check the port printed by Vite; use an explicit free port. |

## Definition of done

A stranger can clone the repository, run `npm install && npm run dev`, understand the contracts, regenerate the art, verify the interactions, and publish their own copy without asking the original author anything.
