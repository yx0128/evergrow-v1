# Changelog

All notable changes to Evergrow are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Task planning: subtasks with progress bars and inline title editing, priority levels, deadlines, status/priority/date/no-date filters, and automatic completion → due-date → priority sorting.
- A compact task bar and a full-screen task tab with List, Month, Week, and Day views. Month and Week support drag-to-reschedule.
- A music and ambience player with play/pause/skip, optional looping and loop duration, independent volume, and mute. Nothing autoplays.
- Normal and pomodoro focus sessions with configurable duration, break length, and block count. Timers survive closing their panel, show remaining time in the top capsule, toast on phase changes, and chime when a block ends.
- Selling from inventory or directly from the world for a full refund.

### Changed

- New worlds start empty: zero coins, no tasks, no inventory, and no placed pieces.
- The task UI starts as a side bar, can dock as a full tab, and keeps task creation in the bar. Clicking a task title edits its deadline and priority; subtasks have their own collapsed checklist.
- The pomodoro capsule is green during focus blocks and gold during breaks.
- Task drawer margins, scrolling, the calendar month grid, and the task tab layout were tightened for 1440×900 and 1280×800.
- The project is now **Evergrow** everywhere, including the package name, storage key (with a legacy-key migration), skill folder, docs, and live demo links.

## [1.0.0] — 2026-11-21

### Added

- Desktop-first React 18 + TypeScript + Vite application.
- Three.js floating `1×1` diorama with `fov 32` isometric camera, orbit/pan/zoom, and camera reset.
- Task → coin economy with Quick (10), Standard (25), and Deep Work (50) rewards.
- 3×3 sandstone starter courtyard, 80 starting coins, and two starter props.
- Two-layer placement: base tiles at `y=0`, surface props at `y=0.2333`.
- Ghost preview with validity tinting, 90° rotation (`R`), right-click storage, and store mode.
- Day/night themes with warm sun, clean day-mode negative space, starfield, moon, lantern/firepoint lights, subtle bloom, ACES tone mapping, and warm golden-yellow lantern/firepot glow in every mode.
- Collapsible task panel, inventory hotbar with `1–9`, build shop with base/prop filters, toasts, controls legend, and photo mode.
- Validated Zustand `localStorage` persistence with schema versioning and hostile-data sanitization.
- Thirteen Blender-sculpted GLB miniatures generated by `scripts/generate_models.py`, with runtime auto-normalization, grounding, shadows, and a labeled fallback.
- Web Audio task/placement/purchase chimes.
- 14 Vitest store tests.
- Professional documentation, CI workflow, issue/PR templates, and a reusable agent skill.
- GitHub Pages deployment from `main`, with subpath-safe assets and GLB URLs.

### Known limitations

- Desktop-first layout; smaller screens are usable but denser.
- Single local save; no accounts or cloud sync.
- Placement plane spans ±110 cells while the store allows ±250.
