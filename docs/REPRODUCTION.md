# Reproduction guide

This document is the complete recipe for rebuilding **Moss & Ember** from an empty directory, including the art. It is written for a human developer or an AI coding agent with shell access.

## 0. Target outcome

A desktop-first browser app at `http://localhost:5173` with:

- a React 18 + TypeScript + Vite client;
- a Three.js scene with `fov 32` isometric camera, floating `1×1` grid, day/night lighting, subtle bloom, ACES tone mapping, and shadows;
- a fixed ten-light pool, instanced placed items, and a lazy-loaded High/Low graphics preset;
- 13 real `.glb` miniatures generated by Blender;
- a task → coin → shop → inventory → placement loop;
- validated `localStorage` persistence;
- a professional documentation and CI surface.

## 1. Environment

```bash
node --version    # 20+ (built on 26.13.1)
npm --version     # 10+
blender --version # 4.2+ (built with 5.3.0), or use the macOS app bundle
```

## 3. Configuration files

Create:

- `vite.config.ts` — React plugin, port `5173`, manual chunks for `three`, `@react-three`, React vendor; Vitest `jsdom` + `src/test/setup.ts`.
- `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json` — strict, `noUnusedLocals`, `noUnusedParameters`, `types: ["vitest/globals"]`.
- `tailwind.config.js` — design tokens from [DESIGN.md](DESIGN.md); display/sans stacks; panel/toast animations.
- `postcss.config.js` — Tailwind + autoprefixer.
- `eslint.config.js` — flat config with TypeScript, React hooks, React refresh, browser globals.
- `index.html` — title `Moss & Ember · Cozy Task World`, favicon, description, `#root`.
- `.editorconfig`, `.gitignore`, `.nvmrc`.

`.gitignore` must include `node_modules/`, `dist/`, `coverage/`, `*.tsbuildinfo`, `.DS_Store`, `.env*`, and Blender backups (`*.blend1`, `*.blend2`).

## 4. Domain first

Create `src/types.ts` with `ItemDef`, `Task`, `PlacedItem`, `PersistedWorld`, `ActionResult`, `ThemeMode`, `TaskTier`, `Rotation`.

Create `src/data/items.ts`:

- 13 items (5 base, 8 props) with `id`, `name`, `category`, `cost`, `modelUrl`, `blurb`, `accent`, `glyph`, optional `light`.
- costs: 12/16/14/30/34 for bases; 40/55/22/48/30/85/110/32 for props.
- rewards: quick 10, standard 25, deep 50.
- starter: 80 coins, 9 sandstone tiles at `(-1..1, -1..1)`, inventory `{ stone_lantern: 1, rose_planter: 1, cottage: 1, pine_tree: 1 }`, three gentle starter tasks.
- `BASE_HEIGHT = 0.2333`, `FOOTPRINT = 0.96`.

Create `src/lib/grid.ts` (`cellKey`, `findBase`, `findProp`, `worldToCell`, `rotationToRadians`), `src/lib/id.ts` (`crypto.randomUUID` with fallback), `src/lib/sound.ts` (Web Audio chime/place/buy/store/error/UI).

## 5. Store and tests

`src/store/useWorldStore.ts`:

- `createDefaultData()` returns a fresh starter world.
- Zustand `persist` with key `moss-and-ember-v1`, version `1`.
- `partialize` to the five persisted fields only.
- `merge` → `sanitizePersisted(persisted)` + `hydrated: true`.
- strict sanitizers for tasks, inventory, placed items, coins, theme.
- actions per [ARCHITECTURE.md](ARCHITECTURE.md#actions).
- safe storage with an in-memory fallback if `localStorage` throws.

Write 24 Vitest tests covering the matrix in [QA.md](QA.md#4-manual-interaction-checklist). On Node 26, jsdom may expose no `localStorage`; polyfill it in `src/test/setup.ts`.

```bash
npm test
npm run typecheck
```

Do not proceed to the canvas until the store is green. The 3D layer is much easier to debug when the economy is already trustworthy.

## 6. Canvas

### 6.1 GLB loader

`src/components/canvas/MiniatureModel.tsx`:

```ts
const { scene } = useGLTF(item.modelUrl);
const clone = scene.clone(true);
const box = new THREE.Box3().setFromObject(clone);
const size = box.getSize(new THREE.Vector3());
const center = box.getCenter(new THREE.Vector3());
const horizontal = Math.max(size.x, size.z, 0.0001);
const scale = FOOTPRINT / horizontal;
const verticalScale =
  item.category === 'base' ? BASE_HEIGHT / Math.max(size.y, 0.0001) : scale;
const offset = [-center.x * scale, -box.min.y * verticalScale, -center.z * scale];
```

Traverse to enable shadows and swap materials in ghost mode. Wrap with an error boundary and Suspense fallback so a missing GLB renders a labeled beveled block rather than crashing. Add night point lights for `stone_lantern` and `firepot`. Animate placement scale with `easeOutBack` using `Date.now()`.

### 6.2 Diorama

`Diorama.tsx`:

- render base pieces at `y = 0`, props at `y = 0.2333`;
- piece `onClick`/`onContextMenu` call `stopPropagation` and either remove or explain the invalid placement;
- one invisible `planeGeometry` `220×220` at `y = 0` handles `pointermove` and `click`;
- ghost uses the same model with green/coral material and a faint cell tint;
- preload all models once.

### 6.3 Scene

- `<Canvas shadows dpr={[1, 1.75]} camera={{ position: [7.4, 8.4, 9.6], fov: 32, near: 0.1, far: 160 }}>`
- ACES Filmic tone mapping, exposure `1.05` by day and `1.15` at night.
- Alpha-transparent Canvas over the app wrapper's CSS cream/night; fog uses the palette background so the backdrop matches in both quality modes.
- Day: cream background, warm sun `#FFF5E4` `2.35`, hemisphere fill at `0.95`, day fog at near `80` / far `220`, clean negative space (no particles).
- Night: deep espresso-charcoal `#161412`, sparse warm star sprites, pale-cream moonlight `#EDE6D6` at `0.85`, warm taupe-cream hemisphere fill at `0.75`, a soft `#9BA4D4` rim light, exposure `1.15`, and ten warm pooled lights, with stronger bloom.
- `<Grid infiniteGrid fadeDistance={30} fadeStrength={2} />`.
- `OrbitControls` with `LEFT: -1`, right rotate, middle pan, polar clamp `0.2..0.475π`.
- `EffectComposer` → `Bloom (threshold 1.1, intensity 0.45)` → `ToneMapping ACES_FILMIC`, in a lazy `Effects.tsx`. No AO/grading/vignette; High colors match Low while lanterns/firepots bloom.
- Ten permanent pooled point lights in `LightingPool`; never per-miniature lights.
- Placed items through `InstancedItemBatch`; ghost/fallback keep `MiniatureModel`.
- Camera reset via a signal prop; set position/target and `update()`.
- High/Low quality is persisted; Low skips the composer, caps DPR at 1.25, and uses 1024² shadows.

## 7. HUD

- `TopBar`: coin counter, day/night, reset camera, photo mode.
- `TaskDrawer`: collapsible glass panel, progress, tier selector with rewards, checkbox completion, delete, reset with confirmation.
- `InventoryHotbar`: 9 slots, stock badges, `1–9` labels, rotate/store/shop controls; selected item is lifted and ringed.
- `BuildShop`: modal, base/prop tabs, affordable/disabled buy states, owned counts.

- `App.tsx` owns the keyboard map (`1–9`, `R`, `B`, `H`, `Esc`), toast timers, feedback sounds, and the UI/photo mode switch.

Tailwind styling lives in `src/index.css` (`glass-panel`, `glass-pill`, `hud-button`, focus rings, scrollbars). Keep panels cream in both themes.

## 8. Blender art

Create `scripts/generate_models.py` and `scripts/generate_models.sh`, then run:

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/generate_models.py
```

The script must:

1. Use bevel, subdivision, bmesh jitter, lathe, and bezier tubes; no bare cubes.
2. Create Principled BSDF materials with roughness `0.82–0.90`, translucent water, and emission strength `4.0` for lanterns/flames.
3. Join all parts, apply modifiers, center X/Z, ground at `Z = 0`.
4. Enforce base tiles `1.0×1.0×0.2333` and props `≤0.92×0.92`.
5. Export each model with `export_format="GLB"`, `export_apply=True`, `export_yup=True`.

Verify all 13 files and dimensions. Full details: [ART_PIPELINE.md](ART_PIPELINE.md).

## 11. Publish without Keychain loops

The goal is one credential read, then non-interactive pushes.

```bash
# one shell, one keychain read
export GH_TOKEN="$(gh auth token)"
gh repo create USER/REPO --public --description "Moss & Ember — a cozy 3D isometric task diorama."

git init -b main
git add -A
git commit -m "Initial commit: Moss & Ember"
git remote add origin "https://github.com/USER/REPO.git"

export GIT_ASKPASS="$(mktemp -t askpass)"
cat > "$GIT_ASKPASS" <<'SH'
#!/bin/sh
case "$1" in
  Username*) printf 'x-access-token\n' ;;
  Password*) printf '%s\n' "$GH_TOKEN" ;;
esac
SH
chmod 700 "$GIT_ASKPASS"
GIT_TERMINAL_PROMPT=0 git -c credential.helper= push -u origin main
```

Do not put the token in the remote URL, `.git/config`, a committed file, or shell history. Do not force-push shared repositories.

### GitHub Pages

The app is a static SPA with no client router, so Pages only needs the built `dist/` directory. Add `.github/workflows/pages.yml` (configure-pages, upload-pages-artifact, deploy-pages) and set `VITE_BASE_PATH=/<repo-name>/` for the build. `vite.config.ts` reads that variable into `base`, and `src/data/items.ts` prefixes every GLB URL with `import.meta.env.BASE_URL`; without both, the project-subpath build will request `/models/...` at the domain root and the miniatures will 404. Enable Pages with `build_type=workflow`:

```bash
gh api --method POST repos/USER/REPO/pages -f build_type=workflow
```

Expected URL: `https://USER.github.io/REPO/`. Verify the HTML, the JS chunks, and at least one GLB return `200`.

## 13. Pitfalls that cost time

| Pitfall | Prevention |
| --- | --- |
| React 19 peer conflicts | Pin React 18 / R3F 8 / drei 9. |
| `LEFT: -1` type error | Cast to `unknown as THREE.MOUSE`. |
| Base tiles sink or props float | Height-lock base tiles to `0.2333` after horizontal normalization. |
| jsdom has no `localStorage` on Node 26 | Polyfill in `src/test/setup.ts` and use a safe storage adapter. |
| Blender 5.x socket KeyError | Use `Emission Color`, `Emission Strength`, `Transmission Weight`. |
| Blender exporter ignores bevels | `export_apply=True`. |
| Wrong up axis | `export_yup=True`; keep `Z=0` ground in Blender. |
| Ghost never appears over tiles | Keep the raycast plane at `y=0` and stop propagation on pieces. |
| Vite preview hits the wrong app | Pass an explicit free port and verify the page title. |
| Keychain prompts on every push | One `gh auth token`, `GIT_ASKPASS`, `credential.helper=`. |
| Grid looks like clipped text at the horizon | Use `fadeDistance 30`, `fadeStrength 2`, low-contrast grid colors. |
| Bloom washes out the scene | Lower intensity, keep threshold at `1.1`. |
| Lantern placements stutter the shader | Never add per-miniature lights; keep the ten-light pool. |
| High/Low toggle remounts the scene | Update DPR through `setDpr`, shadow map size, and the effects gate; do not remount the Canvas. |
